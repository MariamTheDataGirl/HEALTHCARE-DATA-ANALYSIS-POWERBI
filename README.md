
Healthcare Data Analysis & Visualization using Power BI
Project Overview
This project focuses on analyzing healthcare data to uncover insights into patient demographics, medical conditions, billing trends, and hospital stay patterns. The analysis was carried out using Power BI to create an interactive dashboard that supports data-driven decision-making in healthcare.

Objectives
The main objectives of this project are to:
* Analyze patient distribution by age group and gender.
* Identify the most common medical conditions.
* Examine billing amount trends.
* Evaluate patient length of stay.
* Provide insights through interactive visualizations.

Business Questions
This project answers the following questions:
1. How many patients are included in the dataset?
2. What is the average patient age?
3. Which medical conditions are most common?
4. How are patients distributed across age groups?
5. What is the relationship between billing amount and length of stay?
6. What trends exist in hospital admissions?

Tools & Technologies
* Power BI
* Power Query
* DAX
* Microsoft Excel
* Data Visualization

Data Cleaning & Transformation
The following data preparation steps were performed:
* Cleaned and standardized text fields.
* Created Age Group categories.
* Calculated Length of Stay.
* Extracted Admission Month.
* Removed duplicates and handled missing values.
* Built calculated columns and measures using DAX.

Dashboard Features
The dashboard includes:
* Total Patients KPI
* Average Age KPI
* Billing Amount Analysis
* Medical Condition Distribution
* Age Group Analysis
* Length of Stay Analysis
* Interactive Filters and Slicers

Dataset Source
Dataset obtained from Kaggle.
